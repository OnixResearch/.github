# OnixResearch

Languages, build tools, and repository workflows for systems software.

## Projects

| Project | Focus |
| --- | --- |
| [Mantle](https://github.com/OnixResearch/mantle) | Nickel-authored, Rust-implemented builds using the Nix store protocol. |
| [Noble](https://github.com/OnixResearch/noble-lang) | A statically typed concatenative language that compiles to WebAssembly. |
| [Octet](https://github.com/OnixResearch/octet-public) | Rust linting, standards, policy checks, and reviewable evidence artifacts. |
| [Cairn](https://github.com/OnixResearch/cairn-public) | Repository lifecycle workflows with a native `.cairn/` layout and Nickel policy. |
| [Terrane](https://github.com/OnixResearch/terrane) | Verified-logic building blocks with explicit specifications and assumptions. |
| [Nickel Export](https://github.com/OnixResearch/nickel-export) | Deterministic Nickel exports with content identities, receipts, and freshness manifests. |

[Browse all public repositories](https://github.com/orgs/OnixResearch/repositories).

## Status and scope

These projects are under active development. Some repositories are source-only publications or independent public exports. Read the selected branch's README for its status, dependency availability, and supported workflows. Public source and historical evidence do not establish release readiness.

## Contributing

Start with the affected repository's README and contribution instructions, then the [shared contribution guide](https://github.com/OnixResearch/.github/blob/main/CONTRIBUTING.md). Report bugs and propose changes in the relevant repository, not in this organization-profile repository.
