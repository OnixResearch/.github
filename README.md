# OnixResearch community defaults

This public repository supplies the [OnixResearch organization profile](https://github.com/OnixResearch) and default community files for repositories without their own equivalents.

| Path | Purpose |
| --- | --- |
| `profile/README.md` | Public organization overview. |
| `CONTRIBUTING.md` | Shared contribution guidance. |
| `SUPPORT.md` | Project-specific support routing. |
| `.github/ISSUE_TEMPLATE/bug_report.yml` | Reproducible bug-report form. |
| `.github/ISSUE_TEMPLATE/feature_request.yml` | Problem-focused feature-proposal form. |
| `.github/ISSUE_TEMPLATE/config.yml` | Issue chooser configuration; blank issues remain available. |
| `.github/PULL_REQUEST_TEMPLATE.md` | Change, impact, and verification prompts. |

GitHub uses these files as defaults; they do not replace repository-specific instructions. A repository's own `ISSUE_TEMPLATE` folder overrides the shared issue templates as a set. These defaults do not create labels, enable trackers or Discussions, install workflows, or change project licenses or release policies.

For project bugs and proposals, use the affected repository. Changes to the profile or these shared files belong here.

See GitHub's documentation for [organization profiles](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile) and [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
