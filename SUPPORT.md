# Support

Start with the affected repository's README and documentation. Check the selected branch's status and prerequisites, especially for source-only publications and experimental tooling.

- **Bugs:** use the affected repository's issue tracker when enabled. Include the commit or release, a minimal reproduction, expected and observed results, and redacted diagnostic output.
- **Feature proposals:** describe the problem and proposed behavior in that repository, following its contribution instructions.
- **Questions:** use the repository's documented support channel or Discussions when enabled. If no channel is documented and issues are enabled, a focused question in its issue tracker is appropriate.
- **Security-sensitive reports:** follow the repository's security reporting instructions. Use the Security tab's **Report a vulnerability** action when available. Do not post vulnerability details or secrets in public issues.

[Browse OnixResearch repositories](https://github.com/orgs/OnixResearch/repositories) to find the right project. This `.github` repository contains the organization profile and shared community files; it is not a support tracker for all projects.

Repository-specific guidance takes precedence. No response time or support commitment is implied.
